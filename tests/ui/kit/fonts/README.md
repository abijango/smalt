# Test font

`SmaltTestSans-*.ttf` are subsets of DejaVu Sans (Basic Latin, Latin-1 and a few
punctuation marks), renamed to "Smalt Test Sans" as the Bitstream Vera licence
(`LICENSE-DejaVu.txt`) requires for modified fonts. The UI kit tests load them so
golden screenshots render the same text on every machine. They are never shipped
to the device.
